## Install Hermes

Get the package for your computer from [Downloads](/download).

### macOS

1. Download the macOS disk image and open it.
2. Move Hermes to Applications and launch that copy. Keep it in a stable location so macOS can retain its permissions.
3. Grant Accessibility, Microphone, and Input Monitoring access, then restart Hermes. See [Permissions](/docs/permissions).

### Windows

1. Download and run the Windows installer.
2. Launch Hermes.
3. Use a normal, non-elevated app for your first dictation. An unelevated Hermes cannot paste into an elevated app.

### Linux

1. Download the AppImage or Debian package for your Wayland desktop.
2. Make the AppImage executable before launching it, or install the Debian package with your package manager.
3. Check [Linux permissions](/docs/permissions#linux) for keyboard input and paste access.

## First dictation

1. In onboarding, choose **Sign in, free** or **Use my own key**. Connect your account or enter your provider key.
2. Check your microphone in onboarding, or use **Settings → Microphone → Test**.
3. Focus a text field in another app.
4. Hold the right Control key, speak a sentence, and release the key.
5. Wait for transcription and cleanup. Hermes pastes the result into the focused app.

<Callout type="info">Keep the destination app focused until the text is pasted.</Callout>
