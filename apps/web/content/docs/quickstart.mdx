## Install TypeAside

Get the package for your computer from [Downloads](/download).

### macOS

1. Download the macOS disk image and open it.
2. Move TypeAside to Applications and launch that copy. Keep it in a stable location so macOS can retain its permissions.
3. Grant Accessibility, Microphone, and Input Monitoring access, then restart TypeAside. See [Permissions](/docs/permissions).

### Windows

1. Download and run the Windows installer.
2. Launch TypeAside.
3. Use a normal, non-elevated app for your first dictation. An unelevated TypeAside cannot paste into an elevated app.

### Linux

On Linux x86_64, install without root access:

```sh
curl -fsSL https://typeaside.app/install.sh | sh
```

The installer verifies the AppImage's signature and adds TypeAside to your applications menu.
It installs the app under `~/.local/share/typeaside` (or `$XDG_DATA_HOME/typeaside`) and the command at `~/.local/bin/typeaside`.
Run the same command again to reinstall the latest release.

You can also install an [AppImage, Debian or RPM package](/download).
Check [Linux permissions](/docs/permissions#linux) for keyboard input and paste access.

## First dictation

1. In onboarding, choose your transcription source: run models on-device or use your own key. You can change this later in **Settings → Transcription**.
2. Check your microphone in onboarding, or use **Settings → Microphone → Test**.
3. Focus a text field in another app.
4. Hold the right Control key, speak a sentence, and release the key.
5. Wait for transcription and cleanup. TypeAside pastes the result into the focused app.

<Callout type="info">Keep the destination app focused until the text is pasted.</Callout>
