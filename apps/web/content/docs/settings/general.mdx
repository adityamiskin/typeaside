---
title: General settings
description: Adjust appearance, recording, and startup behavior.
---

Open **Settings** in the desktop app. Changes are saved as you make them.

## Appearance

**Theme** offers **System**, **Light**, and **Dark**. System follows your desktop theme. This setting affects the desktop app.

## Recording

- **Shortcuts:** change Dictate, Command, Paste last, and Cancel. Dictate supports Hold or Toggle.
- **Microphone → Input:** choose a device or System default. Use **Test** to check input.
- **Sound cues:** enable or disable recording sounds.
- **Lower media volume:** duck media while recording on Linux. It has no effect on macOS or Windows.
- **Press Enter after paste:** optionally send Enter after inserting text. It is off by default.

## Launch at login

Enable **Behavior → Launch at login** to start Hermes when you sign in. Hermes uses XDG autostart on Linux, a LaunchAgent on macOS, and the current-user Run registry key on Windows. It is off by default.

## Configuration

**About → Open config folder** opens the configuration directory. API keys are kept in the operating system's credential store separately from the configuration file.
