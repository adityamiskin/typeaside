## Hosted transcription

The TypeAside hosted proxy forwards audio to the transcription provider and text to the editing provider. The proxy does not retain audio or request contents. It stores account, subscription, device, and weekly word usage records. Provider processing and retention are governed by that provider's policies.

## Bring your own key

With **Own key**, the desktop app sends requests directly to your configured transcription and editing providers. Their policies apply to the audio and text you send.

## On your computer

TypeAside records audio in memory for processing. Dictation history is saved locally in `history.jsonl` in the app's data directory. History includes raw and cleaned text, app identifiers, timing, and mode. Treat that file as private text.

API keys and desktop credentials use your operating system's credential store. Ordinary configuration, dictionary terms, and snippets are saved in the local configuration file.

## Clipboard

TypeAside uses the clipboard to insert text. On macOS and Windows it preserves plain text or images around copy/paste, but does not preserve every clipboard format, such as rich text metadata or file lists.

See the site's [Privacy page](/privacy) for the current policy draft.
