title: Connect the desktop app
description: Link a computer to your Hermes account.
---

## Connect a computer

1. In the desktop app, open **Settings → Account** and choose **Sign in**.
2. Sign in on the web if prompted.
3. Review the desktop connection page and choose **Connect**.
4. Allow the browser to return to the desktop app through its local callback.
5. Select **Hermes account** as the transcription source.

Start this flow from the desktop app. The browser connection needs the app's temporary local callback and state.

## Revoke a computer

1. Open [Account](/account) on the web.
2. Find the connected computer in your device list.
3. Choose **Revoke**.

Revocation invalidates that device's hosted access token. Connect again from the desktop app if you want to use hosted transcription on that computer later.
