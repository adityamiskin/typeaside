## How it works

With **Settings → Editing → AI editing** enabled, TypeAside asks the editing model to remove fillers, repetitions, and stutters, apply spoken corrections, and fix punctuation. For example, “at 2, actually 3” is treated as a correction to “at 3”. AI output can vary. Review important text before sending it.

If the editing request fails, TypeAside falls back to the transcript. You can turn AI editing off to keep the transcription without this cleanup step. Translation can still use the editing model when enabled.

## Choose a style

Open **Style** in the desktop app and choose a tone for each category.

| Category | Default tone |
| -------- | ------------ |
| Personal | Casual       |
| Work     | Casual       |
| Email    | Formal       |
| Other    | Casual       |

- **Formal** requests professional wording and complete sentences.
- **Casual** requests conversational wording with standard capitalization and punctuation.
- **Very casual** requests lowercase, minimal punctuation, and no trailing period.

## How apps are categorized

TypeAside checks the foreground app identifier captured when recording starts. Matching is based on names in that identifier:

- **Personal:** Telegram, WhatsApp, Signal, Discord, Element, Beeper.
- **Work:** Slack, Teams, Linear, Mattermost, Zulip.
- **Email:** Thunderbird, Geary, Evolution, Mail, Betterbird.
- **Other:** everything else, including an unavailable app identifier.

A website opened in a browser is generally categorized by the browser's app identifier, rather than the website.
